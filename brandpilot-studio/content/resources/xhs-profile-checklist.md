# 小红书主页自查清单（20 条）

> 用法：对照下面每一条，能做到就打 ✅，做不到就是你下一个要改的点。10 分钟过一遍，主页就能上一个台阶。

## 一、头部（别人 3 秒内看到的）
1. ✅ 昵称里有「你是谁 / 帮谁」的关键词（不是纯网名）
2. ✅ 头像清晰、有人物或品牌感，不是默认灰头像
3. ✅ 简介第一行就说清「我能帮你解决什么」
4. ✅ 简介里有一个明确的「下一步」（看置顶 / 领资料 / 私信）
5. ✅ 没有大段自夸，也没有「记录生活点滴」这种万能废话

## 二、定位（让人一眼记住你）
6. ✅ 一句话能说清你的账号是做什么的
7. ✅ 你的内容服务于一类具体人群，而不是「所有人」
8. ✅ 和同类账号比，你有一个差异点（人群 / 风格 / 方法）
9. ✅ 别人看完知道「关注你能得到什么」
10. ✅ 头图 / 背景图和你的定位一致，不是随手放的图

## 三、内容（决定别人要不要关注）
11. ✅ 前三屏笔记封面风格统一（颜色 / 字体 / 排版）
12. ✅ 封面有大字标题，手机上一眼能看清
13. ✅ 至少有 1 篇「置顶 / 代表作」能说明你的价值
14. ✅ 选题围绕同一主题，而不是东一篇西一篇
15. ✅ 标题有「钩子」，让人想点进去（痛点 / 数字 / 反常识）

## 四、信任与转化（决定别人要不要找你）
16. ✅ 有可信的「证据」：案例 / 过程 / 真实变化（不夸大）
17. ✅ 有明确的联系方式或引导（合规前提下）
18. ✅ 没有「保证涨粉 / 保证成交」这类违规承诺
19. ✅ 评论区有互动，不是冷冰冰没人理
20. ✅ 整个主页看下来，气质统一、像「一个认真的人」

---

### 自查完，得分怎么看
- **16–20 条 ✅**：主页很能打，重点放在持续产出。
- **10–15 条 ✅**：基础不错，定位和封面再统一一下就能提升一档。
- **10 条以下 ✅**：先别急着发笔记，先把「定位 + 简介 + 封面」三件事改好，事半功倍。
