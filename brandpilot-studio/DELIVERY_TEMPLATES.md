## 一、客户意向问卷（成交后第一时间发）

> 直接复制发给客户，让 ta 填空。能不能填清楚，决定了你后面省不省心。

```
【个人品牌起步包 · 开工问卷】
为了给你做到位，麻烦花 10 分钟填一下 👇（填不全也没关系，剩下的我们聊）

A. 关于你
1. 你的身份/职业是？
2. 你最想服务、最想吸引的是哪一类人？（越具体越好）
3. 你希望别人看完你的主页，下一步做什么？（关注/私信/约你/下单/投简历）

B. 关于内容
4. 你做过最有代表性的 3 件事 / 项目 / 作品是？（各一句话）
5. 别人通常因为什么来找你？你最擅长解决的问题是？
6. 你和同行相比，不一样在哪？（风格/经历/方法/价值观）

C. 素材
7. 头像/品牌图、作品图、产品图（能发的都发我，越多越好）
8. 现有的小红书/领英/网站链接（如果有）
9. 你喜欢的风格参考（截图 2–3 个你觉得好看的主页/账号）

D. 其他
10. 期望完成时间？有没有 deadline？
11. 还有什么想让我知道的？
```

## 二、一页式主页文案模板（你内部用来产出）

> 按区块填，填完就是主页文案。求职 / 个人IP / 小商家通用，按需删减。

```
■ HERO（第一屏）
姓名/品牌名：__________
一句话定位：我帮【谁】，解决【什么问题】，通过【交付什么】。
身份标签：__________ · __________
CTA 按钮文字：__________（如：联系我 / 预约体验 / 导航到店）

■ ABOUT / 我能帮你
3–4 句话：背景 + 最擅长的 2–3 件事 + 一句价值主张。

■ 核心内容（项目 / 服务 / 招牌，2–4 个，统一结构）
① 标题｜一句话背景。做了什么 → 用了什么 → 带来什么结果（尽量量化）。
② ……
③ ……

■ 信任证据
案例 / 学员变化 / 用户评价 / 作品（诚实、可核实，不夸大）。

■ 怎么开始 / 联系
明确的下一步 + 联系方式（微信/邮箱/链接）。一句邀请语。
```

写作铁律：① 一句话定位 > 一堆形容词；② 能量化就量化；③ 整页 30 秒读完。

## 四、项目交付清单（自检，交付前逐项打勾）

```

□ 约定数量的封面模板已交付（399=1 / 699=3 / 1299=5）
□ （Pro）私信转化话术已交付
□ 所有占位符 / 示例文字已替换成客户真实信息
□ 错别字、标点、链接已校对
□ 交付物已打包（链接 + 文档 + 模板文件）
```

## 五、修改政策（交付时一并说明，避免无限改）

```
【修改说明】
· 套餐含免费修改：399=1 轮，699=2 轮，1299=2 轮。
· 「1 轮」= 你把所有想改的点一次性列给我，我统一改一版。
· 修改范围：文案措辞、版式细节、信息增删、风格微调。
· 大方向（定位、人群）我们在第二步「定位梳理」时就会确认，
  以避免做完才推翻、互相浪费时间。
· 超出免费轮次，或更换大方向重做，按 100/轮 计（提前告知，绝不偷偷收费）。
· 交付后 7 天内提出的修改都算在免费轮次内，过期可少量补差价。
```
